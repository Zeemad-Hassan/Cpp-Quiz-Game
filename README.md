# C++ Quiz Game

A console-based C++ quiz game containing multiple-choice questions about C++ programming fundamentals.

## Features

- Multiple-Choice Questions
- Four Options for Each Question
- Automatic Answer Checking
- Score Calculation
- Correct Answer Count
- Wrong Answer Count
- Percentage Calculation
- Grade Calculation
- Final Result Display

## Quiz Topics

The questions cover basic C++ concepts such as:

- Arrays
- Structures
- Loops
- Functions
- Operators
- Data Types
- Switch Statements
- Program Structure

## Concepts Used

- C++
- Structures
- Arrays
- Functions
- Loops
- If-Else Statements
- Switch Statement
- User Input
- Basic Calculations

## Purpose

This project was created to practice C++ fundamentals while building an interactive console-based quiz application.
